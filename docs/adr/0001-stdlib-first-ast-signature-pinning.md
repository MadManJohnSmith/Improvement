# Extracción determinista de firmas AST en librería estándar sin dependencias canónicas

El árbol canónico de `Improvement` prohíbe instalar paquetes externos (`pip`/`npm`) para garantizar ejecución offline, reproducible y auditable en cualquier entorno Linux con Python 3 (decisión consolidada al declinar `F5B` en `PLAN_IMPLEMENTACION.md`). Para implementar el Filtro 1 (`Contract Hash`) y el Filtro 2 (`Body LSH`, churn semántico y entropía de Shannon) sin violar esta restricción, decidimos construir el núcleo de `scripts/drift.py` 100% sobre la librería estándar de Python (`ast` y `tokenize` para Python, más un tokenizador y extractor estructural determinista de declaraciones exportadas con balanceo de delimitadores y descarte de comentarios para TypeScript, JavaScript, Rust y Go, inspirado en el verificador `type-equiv` de DeepSeek Harness). Los binarios externos de parseo (como `tree-sitter` o `tsc`) se admiten únicamente como capacidades opcionales declaradas y verificadas por digest en `scripts/stack.py`, sin ser requisito para que el motor opere ni para que la suite de pruebas pase.
